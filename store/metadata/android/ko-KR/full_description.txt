CaptureCam은 광고, 계정, 인터넷 접속이 없는 간단한 무료 화면 녹화 앱입니다. 녹화한 영상은 휴대전화 밖으로 나가지 않습니다.

원하는 대로 녹화
• 전체 화면 또는 특정 앱 하나만 녹화
• 언제든지 일시중지하고 재개
• 준비할 수 있도록 화면에 3-2-1 카운트다운 표시(선택 사항)
• 앱을 열지 않고도 빠른 설정 타일로 녹화 시작 및 중지
• 알림에서 바로 제어

내 방식대로 영상 만들기
• 해상도(화면 원본 크기까지), 초당 프레임 수, 화질 선택
• 세로, 가로 또는 자동 화면 방향
• 앱 소리 녹음(기본값 켜짐), 마이크 소리 녹음은 선택 사항
• 표준 MP4 파일로 영화 또는 다운로드 폴더에 저장되어 바로 공유 가능

내장 갤러리
• 최근 녹화본을 깔끔한 격자 형태로 확인
• 앱 안에서 바로 미리보기
• 한 번의 탭으로 공유, 다른 앱으로 열기, 삭제

설계부터 프라이버시 중심
• 광고와 트래커 없음
• 앱에 인터넷 권한조차 없어서 어디로도 데이터를 보낼 수 없음
• 무료 오픈소스

알아 두세요
• Android 11 이상 필요
• 앱 소리는 앱마다 다릅니다. 오디오 캡처를 막는 앱과 보호된 콘텐츠는 소리 없이 녹화됩니다
• 화면 캡처를 차단하는 앱(일부 은행·동영상 앱)은 검은 화면으로 녹화됨
• 선택 사항인 “다른 앱 위에 표시” 권한은 화면 카운트다운을 표시하는 용도로만 사용

궁금한 점이나 아이디어가 있나요? 소스 코드와 연락처는 앱 안의 “CaptureCam 정보”에서 확인할 수 있습니다.
